How This Demo Works

This is a simulation of the StableReceipt Solana system. In a real implementation, this would:

  • Query Solana RPC for USDC transfers to the specified wallet
  • Match transactions to the provided invoice ID
  • Generate a professional PDF receipt with USD valuation
  • Integrate with MultiHopper for optimized payment routing

Note: This demo runs locally and does not connect to actual Solana networks or MultiHopper API.
